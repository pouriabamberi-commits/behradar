# Behradar Academy — Node.js 13.14.0 + SQLite3 5.0.2

این نسخه بدون تغییر اساسی در UI سایت، بک‌اند و پنل مدیریت را به SQLite وصل می‌کند.

## نسخه‌های هدف
- Node.js: 13.14.0
- sqlite3: 5.0.2
- Express: 4.17.1

## نصب
داخل ریشه پروژه:

```bash
npm install
```

سپس:

```bash
node app.js
```

سرور:
`http://localhost:3000`

داشبورد:
`http://localhost:3000/admin`

## ورود استاد اصلی
- شماره: `09000000000`
- رمز: `123`

بعد از ورود، استاد می‌تواند نام، حوزه کاری، رمز و حالت روشن/تاریک را تغییر دهد.

## درخواست ورود استاد جدید
از صفحه `/admin` گزینه «درخواست ورود استاد جدید» را بزنید. استاد متقاضی نام، شماره و رمز دلخواهش را ثبت می‌کند. درخواست در داشبورد/پیام‌ها دیده می‌شود. بعد از تأیید، همان رمز برای ورود فعال می‌شود.

## دیتابیس
فایل SQLite در اولین اجرا خودکار ساخته می‌شود:
`data/behradar.sqlite3`

جداول اصلی:
- users
- otp_codes
- access_requests
- articles
- article_blocks
- files
- messages
- tests
- test_questions
- test_results
- settings

## مقالات
مقاله از `admin/articles-create.html` با بلوک‌های پاراگراف، تیتر، نکته مهم و لیست ساخته می‌شود. بعد از ذخیره، مقاله در `blog.html` و جزئیات آن در `blog-details.html?id=...` با همان قالب موجود سایت نمایش داده می‌شود.

## فایل‌ها
از `admin/downloads-manage.html` فایل برای پایه و موضوع مشخص آپلود یا حذف می‌شود و فایل‌های جدید در `downloads.html` نمایش داده می‌شوند.

## آزمون تعیین سطح
آزمون‌های داخلی هم‌راستا با CEFR برای A1 تا C2 در SQLite seed می‌شوند. این آزمون‌ها آزمون رسمی IELTS/TOEFL نیستند.

## نکته توسعه
برای محیط واقعی بهتر است SESSION_SECRET در متغیر محیطی قرار گیرد، HTTPS فعال شود و برای OTP یک سرویس پیامک واقعی متصل شود. نسخه فعلی برای اجرای محلی و توسعه پروژه آماده شده است.
